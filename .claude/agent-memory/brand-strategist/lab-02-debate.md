## สิ่งที่เรียนรู้เกี่ยวกับเจ้าของเว็บ

- คนดูหลักคือ HR และลูกค้าฟรีแลนซ์ — ไม่ใช่เพื่อนร่วมสายเทค ศัพท์เทคนิคต้องแปลเป็นผลลัพธ์เสมอ
- เจ้าของเลือกไม่เปิดตัวตนเต็มที่ (ยังไม่เปิด GitHub/LinkedIn ตาม D13) — งาน brand ต้องทำงานได้โดยไม่พึ่งลิงก์โซเชียลและไม่พึ่ง case study
- จุดต่างที่ใช้ได้จริงมีจุดเดียว คือการทำให้ AI agent หลายตัวทำงานร่วมกันผ่านเอกสารและ PR — ห้ามทิ้งจุดนี้เพื่อความปลอดภัย แต่ต้องผูกกับขอบเขตที่พิสูจน์ได้ (D10)

## บทเรียนวิธีทำงาน

- คำลดทอนตัวเอง ("กำลัง" / "สนใจ" / "ช่วงหลัง") เป็นศัตรูหลักของไฟล์นี้ — มันโผล่ซ้ำทุกครั้งที่เขียนใหม่ เช็กก่อนส่งงานทุกรอบ (D2 เขียนเป็นกติกาใน `## Tone` แล้ว)
- ของดีที่สุดในไฟล์มักถูกฝังไว้ย่อหน้าท้าย ๆ — หน้าที่ของ brand คือดันขึ้นมาข้างบน ไม่ใช่เขียนของใหม่
- ตอนถกเรื่อง Guestbook ผมถอนออกจาก Must เอง เพราะสมุดเยี่ยมว่างเปล่าบนเว็บที่ HR ดู เป็นลบมากกว่าบวก — จุดยืนนี้ยังใช้ได้
