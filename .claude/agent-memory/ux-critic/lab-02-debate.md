## บทเรียนวิธีทำงาน (สำคัญที่สุด)

- **อย่าเชื่อเอกสาร ให้เปิดไฟล์หน้าเว็บดูเอง** — ปัญหาที่ใหญ่ที่สุดสองข้อในรอบนี้ (Audience หลุด · error ดิบ) ไม่มีเขียนอยู่ใน PROFILE หรือ Brainstorm เลย เจอเพราะไปอ่าน `src/pages/` จริง
- **guardrail ที่มีอยู่จับ runtime ไม่ได้** — `tests/public-site.test.ts` สแกนแค่ markup ที่เขียนไว้ในไฟล์ ข้อความที่มาจาก API หรือจาก FALLBACK ตอนรัน มันมองไม่เห็น (D8) ดังนั้น "เทสต์เขียว" ไม่เท่ากับ "ไม่มีคำต้องห้ามบนหน้าจอ"
- ข้อมูลที่เป็น *โน้ตภายใน* (เช่น `Audience`) ต่างจากข้อมูลที่เขียนถึงผู้อ่าน — ทุกครั้งที่หน้าเว็บ render ฟิลด์จาก PROFILE ให้ถามก่อนว่าฟิลด์นี้เขียนให้ใครอ่าน
