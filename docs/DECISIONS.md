## สรุปการโต้วาที

Brand Strategist เสนอให้ตัดคำลดทอนตัวเองออกจากทุกข้อความ แล้วดัน "ทำให้ AI หลายตัวทำงานร่วมกันได้" ขึ้นมาเป็นจุดต่างหลัก แทนที่จะปล่อยให้จมอยู่ย่อหน้าที่ 3 ของหน้า About UX Critic ไม่ได้เถียงเรื่อง copy แต่ชี้ว่าหน้าเว็บที่มีอยู่จริงรั่วสองจุด — หน้าแรกพิมพ์บรรทัด `Audience:` ออกไปให้คนดูเห็น และหน้า Guestbook/Contact เอาข้อความ error ดิบจาก API มาแสดงจนคำว่า "Lab 05 OpenCode" โผล่บนหน้าจอ Devil's Advocate ยกระดับทั้งสองข้อจากเรื่องความสวยงามเป็นความเสี่ยงจริง และเพิ่มอีกสามข้อ: `innerHTML` ในหน้า Guestbook คือ stored XSS ที่รอให้ Lab 05 ทำงานเสร็จเท่านั้น · อีเมลตัวอย่างที่หลุดขึ้นเว็บจริงจะทำให้พลาดงานโดยไม่มีใครรู้ · และการเปิดลิงก์ GitHub เท่ากับเปิดโฟลเดอร์ `docs/` ทั้งโฟลเดอร์ รวมหัวข้อที่เขียนไว้เองว่าไม่ให้เผยแพร่

จุดที่สามบทบาทเห็นตรงกันโดยไม่ต้องไกล่เกลี่ย คือ Guestbook ไม่คุ้มที่จะอยู่ใน v1 — Brand ถอนออกจาก Must เองตั้งแต่รอบ 3 ข้อที่ยังขัดกันจริงมีข้อเดียว คือควรเล่าเรื่อง AI agent ละเอียดแค่ไหนถึงจะไม่กลายเป็น overclaim ซึ่งปิดด้วย D3 + D10 ให้เล่าได้แต่ต้องผูกกับขอบเขตที่พิสูจน์ได้

## สิ่งที่เลื่อนออก (Out of scope v1)

- **Guestbook แบบเขียนได้** — กลับมาพิจารณาเมื่อมีชั้น escape + validate + ทางลบข้อความ ครบทั้งสามอย่าง (D5, D6)
- **Analytics ทุกชนิด** รวมถึงการเก็บ IP เงียบ ๆ — เป็นปัญหา privacy ที่ไม่มีใครร้องขอ
- **Blog engine / CMS · comment system · dark mode toggle · i18n · animation หนัก** — scope creep ตรงตาม `## Brainstorm`
- **Case study และบันทึกสิ่งที่เรียนรู้** — อยากมี แต่ต้องมีของจริงก่อน ไม่ใช่หัวข้อว่าง
- **เปิดลิงก์ GitHub / LinkedIn** — ค้างที่เจ้าของตาม D13
- **รูปหน้า ชื่อองค์กร เรตค่าจ้าง เบอร์โทร** — อยู่ในหัวข้อ `## ไม่เผยแพร่บนเว็บ` ของ PROFILE อยู่แล้ว ไม่รื้อในรอบนี้

## เกณฑ์พร้อม Frontend (Lab 04)

ต้องผ่านครบก่อนถือว่าหน้าเว็บพร้อมให้คนนอกเห็น

1. **P0** — เปิดหน้าแรกแล้ว **ไม่มีคำว่า `Audience:`** และค่า fallback ก็ไม่ใช่ข้อความหางาน (D4 · open loop L7)
2. **P0** — หน้า Guestbook **ไม่ใช้ `innerHTML`** และไม่มีลิงก์ใน nav (D5, D6 · open loop L6)
3. ไม่มีข้อความจากระบบหรือชื่อคอร์สโผล่บนหน้าจอ — ลองยิงฟอร์ม Contact ตอน backend ยังไม่เสร็จ ต้องเห็น "ฟอร์มยังไม่เปิดใช้งาน" ไม่ใช่ `NOT_IMPLEMENTED: ...` (D7, D8 · open loop L8)
4. Bio แสดงครบ 4 ย่อหน้า และ Interests อ่านเป็น `หัวข้อ — คำขยาย` (D12 · open loops L5, L9)
5. ทุกหน้ามี title/description ของตัวเอง · h1 เดียวต่อหน้า · focus มองเห็นได้ตอนกด Tab (D14)
6. `npm test` เขียว — รวม guardrail `tests/public-site.test.ts`

- `## Headline` — เปลี่ยนเป็นข้อความตาม **D1**
