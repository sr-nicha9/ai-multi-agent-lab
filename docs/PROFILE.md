## Bio
ทำงานสาย IT โดยเน้นไปทางเขียนโค้ด ออกแบบระบบ และดูโปรเจ็คให้เดินจบ มากกว่างานดูแล infra หรือ hardware

ใช้ AI เป็นเครื่องมือประจำวันในขั้นตอนการทำงานจริง ไม่ใช่แค่ถามตอบเป็นครั้งคราว — ช่วยเขียนโค้ด อ่านระบบที่ไม่คุ้น และตัดงานซ้ำที่กินเวลาโดยไม่ได้สร้างอะไรใหม่ เป้าหมายคือทำงานเดิมให้ดีขึ้นและเร็วขึ้น ไม่ใช่การเปลี่ยนอาชีพ

งานที่ให้เวลามากที่สุดตอนนี้คือการทำให้ AI agent หลายตัวแบ่งหน้าที่กันชัดเจน แล้วประสานงานผ่านเอกสารและ PR แทนการคุยกันในแชทเดียว ผลคือการตัดสินใจแต่ละอย่างตามย้อนได้จากเอกสาร และคนอื่นเข้ามาทำต่อได้โดยไม่ต้องไล่อ่านบทสนทนาทั้งหมด

จดสิ่งที่เรียนรู้ไว้ระหว่างทาง ทั้งสิ่งที่ได้ผลและสิ่งที่ลองแล้วไม่เวิร์ก เพราะการเขียนสรุปออกมาช่วยให้เข้าใจขึ้น และเป็นทางลัดให้คนที่เริ่มทีหลัง
