## Bio
ทำงานสาย IT โดยเน้นไปทางเขียนโค้ด ออกแบบระบบ และดูโปรเจ็คให้เดินจบ มากกว่างานดูแล infra หรือ hardware

ช่วงหลังสนใจเรื่องการเอา AI เข้ามาอยู่ในขั้นตอนการทำงานจริง ไม่ใช่แค่ถามตอบเป็นครั้งคราว แต่ใช้เป็นเครื่องมือประจำวัน — ช่วยเขียนโค้ด ช่วยอ่านระบบที่ไม่คุ้น ช่วยลดงานซ้ำ ๆ ที่กินเวลาไปเยอะโดยไม่ได้สร้างอะไรใหม่ เป้าหมายไม่ใช่การเปลี่ยนอาชีพ แต่คือการทำงานเดิมให้ดีขึ้นและเร็วขึ้น

สนใจเป็นพิเศษเรื่องการทำงานร่วมกับ AI agent หลายตัวที่แบ่งหน้าที่กันชัดเจน แล้วประสานงานกันผ่านเอกสารและ PR แทนที่จะคุยกันในแชทเดียว วิธีนี้ทำให้งานตรวจสอบย้อนหลังได้ และคนอื่นเข้ามาต่อได้โดยไม่ต้องไล่อ่านบทสนทนาทั้งหมด

ระหว่างทางจะจดสิ่งที่เรียนรู้ไว้เรื่อย ๆ — ทั้งสิ่งที่ได้ผลและสิ่งที่ลองแล้วไม่เวิร์ก เพราะเชื่อว่าการเขียนสรุปออกมาช่วยให้ตัวเองเข้าใจขึ้น และเผื่อเป็นทางลัดให้คนที่กำลังเริ่มเหมือนกัน
